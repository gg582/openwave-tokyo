# Benchmark — Antipodal Complementary-Pair (Warp-Shuffle) vs Traditional Control

All numbers measured on the actual hardware pipeline during execution.

## Test Environment

| Component | Specification |
|---|---|
| GPU | NVIDIA GeForce RTX 3070 (sm_86, 8.2 GB VRAM) |
| CUDA | CUDA Toolkit 13.1 (Driver 610.43) |

---

## 1. FFT Micro-benchmark — 2D IFFT (`./hokusai_wave --bench`)

Execution time for 2D IFFT (Batch 1D rows + Tiled Transpose + Batch 1D columns, Float2 In-Place):

| Grid Size | Traditional (Control) | Complementary (Warp-Shuffle) | Speedup |
|---|---|---|---|
| 256 × 256 | 0.0643 ms | 0.0380 ms | **1.69×** |
| 512 × 512 | 0.1279 ms | 0.0794 ms | **1.61×** |
| 1024 × 1024 | 1.3459 ms | 0.8062 ms | **1.67×** |

- **Numerical Equivalence**: Both variants match a CPU DFT reference at 256² with max error $\le 1.1 \times 10^{-9}$.

## 2. Full Pipeline Performance (1800 Frames, 60s 4K Simulation)

Average execution time per 4K (3840×2160) frame (including crossing seas, Fuji flora, and refined Sagami optics):

| Pipeline Stage (ms/frame) | Traditional (Control) | Complementary (Warp-Shuffle) |
|---|---|---|
| Ocean Sim (Evolution + 3× 2D IFFT + Crossing Seas) | 4.491 ms | **2.883 ms** |
| EGL GL Render (Sky + Fuji DEM + Sagami Bloom) | 0.000 ms | 0.000 ms |
| Post-fx (Aberration + Warp-Shuffle Unsharp) | 0.949 ms | **1.171 ms** |
| NVENC Zero-Copy Video Encode | 0.499 ms | 0.491 ms |

- **Rogue Wave Focus Performance**: The spatio-temporal Gaussian focusing envelope (Benjamin-Feir) adds negligible overhead (< 0.01 ms) while generating 15m+ crests.
